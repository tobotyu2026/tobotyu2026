Game Flow

親子で協力してミッションをクリアせよ！

01
GAME START

ゲームスタート！

全ての回収BOXにタグを10個入れると、最終エリアが解放されるぞ！

02
TAG GET

エンジェルからタグをGET！

タグは全部で4色。1組（1家族）で持てるタグは1個まで。

03
RECOVERY BOX

同じ色の回収BOXへ投入！

GETしたタグは、必ず同じ色の回収BOXへ入れよう。

04
RE-CHALLENGE

BOXに入れたら、再びタグをGET！

回収BOXにタグを入れたら、再びエンジェルからタグをもらえるぞ。

05
FINAL AREA

最終エリアを目指せ！

最終エリア解放後は、ハンターから逃げ切って最終エリアへ向かえ。最後は全員で最終ミッションに挑戦！

Check Point - ここだけチェック！
  • タグは全部で4色
  • タグは1組（1家族）で1個まで
  • GETしたタグは同じ色のBOXへ入れる
  • タグを入れたら、再びエンジェルからタグをGETできる
  • 参加者同士のタグ交換OK
  • タグを持っていれば、ハンターからの確保を1回回避できる
  • タグがない状態で捕まると、親子一緒に牢屋へ移動

覚えておけば安心！

「タグをGET → 同じ色のBOXへ入れる」をくり返せば大丈夫！
